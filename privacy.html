Privacy Policy

Studio Local · Last updated: November 14, 2026 (rev. 2)

Studio Local is a personal application used only by its owner to publish videos to the owner's own YouTube channels. This policy explains what data it accesses and how it is handled.

YouTube API Services

Studio Local uses YouTube API Services. By using Studio Local you agree to be bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

Data accessed

  • YouTube account access granted by the owner through Google OAuth, limited to: uploading videos (youtube.upload) and managing thumbnails, captions and publishing schedule of the owner's own videos (youtube).
  • Video files and metadata created by the owner on their own computer (video, title, description, tags, thumbnail, subtitles, scheduled date).

How data is used

Data is used only to upload and schedule the owner's videos on the owner's channels, and only when the owner starts each upload manually. Studio Local does not read, analyze, sell or share viewers' data or any other user's data.

Storage and security

OAuth tokens and all files are stored only on the owner's computer, in a private folder readable only by the owner's operating-system account. No data is sent to any server other than Google's YouTube Data API.

Sharing

Studio Local does not share any data with third parties. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also follows the YouTube Terms of Service and the Google Privacy Policy.

Retention, revoking access and deletion

OAuth tokens are kept on the owner's computer only while the owner keeps a channel connected. Access can be revoked at any time through the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked or a channel is disconnected, the stored token for that channel is deleted from the owner's computer. Studio Local does not keep any other YouTube API data: the only information it stores after an upload is the link to the owner's own video.
